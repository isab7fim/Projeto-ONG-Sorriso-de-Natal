## Sobre o projeto

O Sorriso de Natal é um projeto acadêmico de desenvolvimento web que apresenta o site institucional de uma ONG fictícia dedicada à solidariedade e ao apadrinhamento de crianças durante o período natalino.
A proposta é divulgar iniciativas sociais, incentivar a participação da comunidade e transmitir a importância de pequenos gestos de solidariedade.

## Objetivo

Desenvolver um site institucional responsivo e interativo, aplicando conhecimentos de HTML5, CSS3 e JavaScript. O projeto busca apresentar a ONG de forma organizada, facilitar a navegação e incentivar o envolvimento da comunidade em ações solidárias.

## Páginas do site

Início (index.html): apresentação da ONG, sua causa e chamada para participação.

Sobre (sobre.html): história, missão, objetivos e público atendido.

Projetos (projetos.html): apresentação das iniciativas sociais e formas de contribuição.

Contato (contato.html): formulário e informações para contato e participação.

## Funcionalidades JavaScript

O projeto possui duas funcionalidades principais:

Validação do formulário: verifica o preenchimento dos campos, o formato do e-mail e o tamanho das informações inseridas, apresentando mensagens de erro ou confirmação simulada.

Interação adicional: permite que o visitante interaja com um elemento da página, atualizando seu conteúdo ou sua visibilidade por meio de JavaScript.

## Tecnologias utilizadas

HTML5: estruturação semântica das páginas.

CSS3: identidade visual, organização dos elementos e responsividade.

JavaScript: validação de formulário e interatividade.

GitHub: armazenamento e versionamento do projeto.

## Como executar o projeto

Baixe o repositório clicando em Code → Download ZIP.

Extraia os arquivos no computador.

Abra a pasta do projeto no Visual Studio Code.

Localize o arquivo index.html.

Abra-o no navegador ou utilize a extensão Live Server.

**Ou**, se preferir, acesse diretamente o site pelo link: [Projeto Sorriso de Natal](COLE_AQUI_O_LINK_DO_SITE).
